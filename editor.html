Scene Index Editor

A local tool for maintaining the scene index. Not linked from the public site.

Honest limitation: this is a static page with no backend, so there's no real password protection here — "private" just means this file isn't linked from the public index. Your edits are saved in this browser only (via localStorage), so they won't appear anywhere else until you download the updated data.js and re-upload it to your GitHub repo. Nothing here talks to Substack or GitHub automatically.
